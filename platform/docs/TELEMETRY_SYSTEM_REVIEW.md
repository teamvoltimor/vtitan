## 1. Executive Summary

The Klevor v2 telemetry system consists of a **FastAPI backend** (Python/Pydantic) and a **React/Three.js frontend** that currently visualizes **synthetic simulation data** generated by a deterministic test generator. The system architecture is well-designed with:

- ✅ Clean separation of concerns (backend/frontend/robot)
- ✅ Type-safe data models (Pydantic backend, TypeScript frontend)
- ✅ RESTful API with CORS support
- ✅ Session recording and replay functionality
- ✅ Real-time 3D visualization with LiDAR point clouds

**Current State**: **Simulation-only** — The backend generates fake telemetry data for UI development. The robot hardware **does not publish telemetry** to the backend.

**Gap**: **No ROS2 → FastAPI bridge exists**. The robot navigator and hardware drivers run independently of the telemetry system.

**Goal**: Enable real-time hardware telemetry visualization with **component independence** (graceful degradation if sensors fail) and **configurable speed limits**.

#### RobotPath

```typescript
function RobotPath({ snapshot }: { snapshot: RobotSnapshot }) {
  const curve = useMemo(() => {
    const pts = snapshot.pathHistory.map((pt) => {
      const [x, y, z] = simToThree(pt)
      return new THREE.Vector3(x, y + 0.03, z)
    })
    return pts.length >= 2 ? new THREE.CatmullRomCurve3(pts) : null
  }, [snapshot])

  const tubeGeometry = useMemo(
    () => (curve ? new THREE.TubeGeometry(curve, 80, 0.01, 5, false) : null),
    [curve]
  )

  if (!tubeGeometry) return null  // ✅ Handles missing data

  return (
    <mesh geometry={tubeGeometry}>
      <meshStandardMaterial color={colors.accent} />
    </mesh>
  )
}
```

**Strengths**:
- ✅ Gracefully handles `pathHistory.length < 2` (returns null)
- ✅ Proper geometry disposal on unmount

**Potential Issue**:
- ⚠️ If `snapshot.pathHistory` is `undefined`, crashes

## 6. Component Independence & Resilience

### 6.1 Problem Statement

**Current behavior**: If any field in `RobotSnapshot` is missing or undefined:
- Backend Pydantic validation **fails** (422 Unprocessable Entity)
- Frontend TypeScript crashes (cannot read property of undefined)
- Entire visualization **breaks**

**Example failure scenario**:
```
1. Robot starts with only IMU working (LiDAR not yet booted)
2. Telemetry bridge tries to publish snapshot with lidarPoints=[]
3. Backend accepts it (empty array is valid)
4. Frontend renders successfully (LiDARPointCloud returns null)

BUT:

1. Robot starts with IMU failing
2. Telemetry bridge has no odometry data
3. Tries to POST with robotPosition=None
4. Backend rejects (Pydantic validation fails)
5. Frontend shows "Unable to load telemetry" error
6. Even though LiDAR/camera/everything else works fine ❌
```

## 7. Speed Configuration Analysis

### 7.1 Current Speed Configuration

**Robot Navigator** (`robot/src/navigation/navigator.py:125`):
```python
self._max_linear_speed: float = 0.50  # 0.50 m/s = 50 cm/s
self._min_forward_speed: float = 0.08  # 0.08 m/s = 8 cm/s
```

**Speed Computation**:
```python
def _compute_nominal_speed(self, angle_error: float, left_dist: float, right_dist: float) -> float:
    speed_fwd = 1.0 if self._lidar_fwd_clear else 0.5
    angle_factor = abs(angle_error) / self._max_steering_angle
    speed_angle = 0.4 if angle_factor > 0.6 else 1.0
    
    raw_speed = self._max_linear_speed * min(speed_fwd, speed_angle)
    return max(raw_speed, self._min_forward_speed)
```

**Effective speed range**:
- **Straight, clear path**: `0.50 * 1.0 * 1.0 = 0.50 m/s` ✅
- **Obstacle ahead**: `0.50 * 0.5 * 1.0 = 0.25 m/s` ✅
- **Sharp turn**: `0.50 * 1.0 * 0.4 = 0.20 m/s` ✅
- **Minimum speed**: `0.08 m/s` (always enforced)

```python
class AckermannMotorNode(Node):
    def __init__(self):
        self.max_speed = MOTOR_MAX_SPEED.value  # 0-100 scale
        
    def _cmd_vel_callback(self, msg: Twist):
        # Convert m/s to motor speed (0-100)
        motor_speed = self._velocity_to_motor_speed(msg.linear.x)
        
        # Clamp to safe limits
        clamped_speed = max(-self.max_speed, min(self.max_speed, motor_speed))
        
        if abs(motor_speed) > self.max_speed:
            self.get_logger().warning(
                f"Motor speed {motor_speed} exceeds limit ±{self.max_speed}, "
                f"clamped to {clamped_speed}"
            )
```

**Configuration**: Environment variable `MOTOR_MAX_SPEED=50` (default 50% power)

### 7.3 Speed Calculation Chain

```
Navigator max_linear_speed (0.50 m/s)
         ↓
    × speed_fwd (0.5 or 1.0 based on obstacle)
         ↓
    × speed_angle (0.4 or 1.0 based on turn sharpness)
         ↓
    = raw_speed (0.08 - 0.50 m/s)
         ↓
    Published as Twist.linear.x
         ↓
    BuildHAT Motor Node receives
         ↓
    Converts to motor speed (0-100 scale)
         ↓
    Clamped by MOTOR_MAX_SPEED env var
         ↓
    Applied to Build HAT motors
```

### 7.4 Answer to User Question

**Q: "Is there configurable the max speed that the robot is capable of, or do it calculates it based on the changes?"**

**A: Both!**

1. **Base max speed is configurable**:
   - Navigator: `max_linear_speed` in `navigator_params.json` (default 0.50 m/s)
   - Motor node: `MOTOR_MAX_SPEED` environment variable (default 50/100)

2. **Speed is dynamically calculated** based on:
   - Forward obstacle clearance (`speed_fwd = 0.5 if obstacle else 1.0`)
   - Steering angle (`speed_angle = 0.4 if sharp_turn else 1.0`)
   - Minimum speed floor (`_min_forward_speed = 0.08 m/s`)

3. **Configuration priority**:
   ```
   MOTOR_MAX_SPEED (hardware limit)
        ↓ (overrides)
   max_linear_speed (navigator config)
        ↓ (modulated by)
   Dynamic speed factors (obstacles, turns)
        ↓ (enforces)
   min_forward_speed (minimum threshold)
   ```

4. **Recommended tuning approach**:
   - Start with `max_linear_speed: 0.30` for initial hardware testing
   - Increase gradually to `0.40 → 0.50 → 0.60` based on track performance
   - Keep `MOTOR_MAX_SPEED=50` until motors/calibration verified
   - Monitor telemetry `speed` field in frontend to see actual speeds

```python
"""ROS2 Telemetry Bridge — Publishes robot data to FastAPI backend."""

from __future__ import annotations

import requests
import time
from collections import deque
from typing import Optional

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan, Imu, JointState
from nav_msgs.msg import Odometry
from std_msgs.msg import String
from geometry_msgs.msg import Twist

class TelemetryBridgeNode(Node):
    """Subscribes to robot topics and POSTs telemetry to backend API."""
    
    def __init__(self):
        super().__init__('telemetry_bridge')
        
        # Configuration
        self.declare_parameter('backend_url', 'http://localhost:8010')
        self.declare_parameter('publish_rate_hz', 10.0)
        self.declare_parameter('max_path_history', 120)
        
        self._backend_url = self.get_parameter('backend_url').value
        self._rate = self.get_parameter('publish_rate_hz').value
        self._max_history = self.get_parameter('max_path_history').value
        
        # Subscriptions
        self.create_subscription(LaserScan, '/scan', self._scan_callback, 10)
        self.create_subscription(Odometry, '/odom', self._odom_callback, 10)
        self.create_subscription(Imu, '/imu/data', self._imu_callback, 10)
        self.create_subscription(String, '/state_machine/state', self._state_callback, 10)
        self.create_subscription(Twist, '/cmd_vel', self._cmd_vel_callback, 10)
        self.create_subscription(JointState, '/joint_states', self._joint_callback, 10)
        
        # Latest data cache
        self._latest_scan: Optional[LaserScan] = None
        self._latest_odom: Optional[Odometry] = None
        self._latest_imu: Optional[Imu] = None
        self._latest_state: str = "unknown"
        self._latest_cmd_vel: Optional[Twist] = None
        self._latest_joints: Optional[JointState] = None
        
        self._path_history: deque = deque(maxlen=self._max_history)
        self._logs: deque = deque(maxlen=10)
        
        # Timer for publishing
        self.create_timer(1.0 / self._rate, self._publish_telemetry)
        
        self.get_logger().info(f"Telemetry bridge started → {self._backend_url}")
    
    def _scan_callback(self, msg: LaserScan):
        self._latest_scan = msg
    
    def _odom_callback(self, msg: Odometry):
        self._latest_odom = msg
        # Add position to path history
        pos = msg.pose.pose.position
        self._path_history.append([pos.x, pos.y, pos.z])
    
    def _imu_callback(self, msg: Imu):
        self._latest_imu = msg
    
    def _state_callback(self, msg: String):
        self._latest_state = msg.data
        self._logs.append(f"State: {msg.data}")
    
    def _cmd_vel_callback(self, msg: Twist):
        self._latest_cmd_vel = msg
    
    def _joint_callback(self, msg: JointState):
        self._latest_joints = msg
    
    def _publish_telemetry(self):
        """Aggregate data and POST to backend."""
        snapshot = self._build_snapshot()
        
        try:
            response = requests.post(
                f"{self._backend_url}/telemetry/record",
                json=snapshot,
                timeout=1.0,
            )
            if response.status_code != 200:
                self.get_logger().warning(f"Backend returned {response.status_code}")
        except requests.exceptions.RequestException as exc:
            self.get_logger().error(f"Failed to post telemetry: {exc}")
    
    def _build_snapshot(self) -> dict:
        """Build RobotSnapshot dict from latest sensor data."""
        timestamp = time.time()
        
        # Robot position (from odometry)
        robot_position = None
        robot_orientation = None
        if self._latest_odom:
            pos = self._latest_odom.pose.pose.position
            robot_position = [pos.x, pos.y, pos.z]
            # Extract yaw from quaternion
            q = self._latest_odom.pose.pose.orientation
            robot_orientation = self._quaternion_to_yaw(q.x, q.y, q.z, q.w)
        
        # LiDAR points (convert to world frame)
        lidar_points = []
        if self._latest_scan and robot_position and robot_orientation is not None:
            lidar_points = self._scan_to_points(
                self._latest_scan,
                robot_position,
                robot_orientation
            )
        
        # Metrics
        metrics = self._build_metrics(timestamp)
        
        # IMU data
        imu_data = None
        if self._latest_imu:
            imu_data = {
                "linearAcceleration": [
                    self._latest_imu.linear_acceleration.x,
                    self._latest_imu.linear_acceleration.y,
                    self._latest_imu.linear_acceleration.z,
                ],
                "angularVelocity": [
                    self._latest_imu.angular_velocity.x,
                    self._latest_imu.angular_velocity.y,
                    self._latest_imu.angular_velocity.z,
                ],
                "orientationQuaternion": [
                    self._latest_imu.orientation.x,
                    self._latest_imu.orientation.y,
                    self._latest_imu.orientation.z,
                    self._latest_imu.orientation.w,
                ],
            }
        
        # Motor state
        motor_state = None
        if self._latest_joints and self._latest_cmd_vel:
            motor_state = {
                "steeringAngle": self._latest_joints.position[0] if len(self._latest_joints.position) > 0 else 0.0,
                "driveSpeed": self._latest_cmd_vel.linear.x,
                "encoderPosition": int(self._latest_joints.position[1]) if len(self._latest_joints.position) > 1 else 0,
            }
        
        return {
            "timestamp": timestamp,
            "missionName": "WRO 2026 Robot",
            "robotPosition": robot_position,
            "robotOrientation": robot_orientation,
            "lidarPoints": lidar_points,
            "pathHistory": list(self._path_history),
            "logs": list(self._logs),
            "metrics": metrics,
            "imuData": imu_data,
            "visionDetections": None,  # TODO: Add YOLO integration
            "motorState": motor_state,
        }
    
    def _build_metrics(self, timestamp: float) -> dict:
        """Build TelemetryMetrics dict."""
        # Sensor availability
        lidar_available = self._latest_scan is not None
        imu_available = self._latest_imu is not None
        odometry_available = self._latest_odom is not None
        camera_available = False  # TODO: Add camera health check
        
        # LiDAR metrics
        points_captured = 0
        range_min = None
        range_max = None
        range_mean = None
        forward = None
        left = None
        right = None
        back = None
        
        if self._latest_scan:
            ranges = [r for r in self._latest_scan.ranges if r > self._latest_scan.range_min and r < self._latest_scan.range_max]
            if ranges:
                points_captured = len(ranges)
                range_min = min(ranges)
                range_max = max(ranges)
                range_mean = sum(ranges) / len(ranges)
                
                # Directional clearances (simplified)
                n = len(self._latest_scan.ranges)
                forward = min(self._latest_scan.ranges[n//2 - 10:n//2 + 10]) if n > 20 else None
                left = min(self._latest_scan.ranges[:n//4]) if n > 4 else None
                right = min(self._latest_scan.ranges[3*n//4:]) if n > 4 else None
                back = min(self._latest_scan.ranges[n//2 - n//8:n//2 + n//8]) if n > 16 else None
        
        # Speed (from cmd_vel)
        speed = None
        if self._latest_cmd_vel:
            speed = self._latest_cmd_vel.linear.x
        
        return {
            "timestamp": timestamp,
            "nodeHealth": "nominal",  # TODO: Add watchdog logic
            "pointsCaptured": points_captured,
            "rangeMin": range_min,
            "rangeMax": range_max,
            "rangeMean": range_mean,
            "forward": forward,
            "left": left,
            "right": right,
            "back": back,
            "speed": speed,
            "stage": self._latest_state,
            "lidarAvailable": lidar_available,
            "imuAvailable": imu_available,
            "cameraAvailable": camera_available,
            "odometryAvailable": odometry_available,
        }
    
    def _scan_to_points(self, scan: LaserScan, robot_pos: list, robot_yaw: float) -> list:
        """Convert LaserScan to world-frame point cloud."""
        import math
        points = []
        for i, r in enumerate(scan.ranges):
            if r < scan.range_min or r > scan.range_max:
                continue
            angle = scan.angle_min + i * scan.angle_increment
            # Local coordinates
            x_local = r * math.cos(angle)
            y_local = r * math.sin(angle)
            # World coordinates
            x_world = robot_pos[0] + x_local * math.cos(robot_yaw) - y_local * math.sin(robot_yaw)
            y_world = robot_pos[1] + x_local * math.sin(robot_yaw) + y_local * math.cos(robot_yaw)
            points.append([x_world, y_world, 0.05])  # z=0.05 for visualization
        return points
    
    def _quaternion_to_yaw(self, x, y, z, w) -> float:
        """Extract yaw angle from quaternion."""
        import math
        siny_cosp = 2 * (w * z + x * y)
        cosy_cosp = 1 - 2 * (y * y + z * z)
        return math.atan2(siny_cosp, cosy_cosp)

    except KeyboardInterrupt:
        pass
    finally:

        rclpy.shutdown()

if __name__ == '__main__':
    main()
```

```typescript
function quaternionToEuler(q: Quaternion) {
  // Convert quaternion to Euler angles (ZYX convention)
  const { x, y, z, w } = q
  
  const roll = Math.atan2(2 * (w * x + y * z), 1 - 2 * (x * x + y * y))
  const pitch = Math.asin(2 * (w * y - z * x))
  const yaw = Math.atan2(2 * (w * z + x * y), 1 - 2 * (y * y + z * z))
  
  return { roll, pitch, yaw }
}
```

- 3D compass needle showing orientation
- Horizontal bars for linear acceleration (3 axes)
- Horizontal bars for angular velocity (3 axes)
- Numeric roll/pitch/yaw display in degrees

```typescript
function CameraStream({ data }: { data: Image }) {
  const canvasRef = useRef<HTMLCanvasElement>(null)
  
  useEffect(() => {
    if (!canvasRef.current) return
    
    const ctx = canvasRef.current.getContext('2d')
    if (!ctx) return
    
    // Convert ROS Image message to canvas
    // data.encoding can be: "rgb8", "bgr8", "mono8", etc.
    const imageData = ctx.createImageData(data.width, data.height)
    
    if (data.encoding === 'rgb8') {
      for (let i = 0; i < data.data.length; i += 3) {
        imageData.data[i * 4 / 3 + 0] = data.data[i + 0]  // R
        imageData.data[i * 4 / 3 + 1] = data.data[i + 1]  // G
        imageData.data[i * 4 / 3 + 2] = data.data[i + 2]  // B
        imageData.data[i * 4 / 3 + 3] = 255                // A
      }
    } else if (data.encoding === 'bgr8') {
      for (let i = 0; i < data.data.length; i += 3) {
        imageData.data[i * 4 / 3 + 0] = data.data[i + 2]  // R (from B)
        imageData.data[i * 4 / 3 + 1] = data.data[i + 1]  // G
        imageData.data[i * 4 / 3 + 2] = data.data[i + 0]  // B (from R)
        imageData.data[i * 4 / 3 + 3] = 255                // A
      }
    }
    
    ctx.putImageData(imageData, 0, 0)
  }, [data])
  
  return (
    <div className="camera-stream">
      <canvas
        ref={canvasRef}
        width={data.width}
        height={data.height}
        style={{ width: '100%', height: 'auto' }}
      />
      <div className="camera-info">
        <span>{data.width}×{data.height}</span>
        <span>{data.encoding}</span>
        <span>{(data.data.length / 1024).toFixed(1)} KB</span>
      </div>
    </div>
  )
}
```

**Features**:
- Real-time video stream
- Supports rgb8, bgr8, mono8 encodings
- Resolution and encoding info
- Frame size display
- Auto-scaling to fit panel

```python
class TelemetryBridgeNode(Node):
    def __init__(self):
        # ... existing code ...
        
        # Raw topic tracking
        self._topic_updates: dict[str, TopicUpdate] = {}
        self._topic_timestamps: dict[str, deque] = {}  # For rate calculation
        
    def _scan_callback(self, msg: LaserScan):
        self._latest_scan = msg
        # Track raw topic
        self._update_raw_topic('/scan', 'sensor_msgs/LaserScan', msg)
    
    def _odom_callback(self, msg: Odometry):
        self._latest_odom = msg
        self._update_raw_topic('/odom', 'nav_msgs/Odometry', msg)
    
    def _imu_callback(self, msg: Imu):
        self._latest_imu = msg
        self._update_raw_topic('/imu/data', 'sensor_msgs/Imu', msg)
    
    def _update_raw_topic(self, topic_name: str, msg_type: str, msg):
        """Track raw topic update for inspector."""
        import time
        from collections import deque
        
        current_time = time.time()
        
        # Calculate update rate
        if topic_name not in self._topic_timestamps:
            self._topic_timestamps[topic_name] = deque(maxlen=10)
        
        self._topic_timestamps[topic_name].append(current_time)
        timestamps = list(self._topic_timestamps[topic_name])
        
        if len(timestamps) >= 2:
            time_diff = timestamps[-1] - timestamps[0]
            update_rate = (len(timestamps) - 1) / time_diff if time_diff > 0 else 0.0
        else:
            update_rate = 0.0
        
        # Convert ROS message to dict
        msg_dict = self._msg_to_dict(msg)
        
        self._topic_updates[topic_name] = {
            "topicName": topic_name,
            "messageType": msg_type,
            "timestamp": current_time,
            "updateRateHz": round(update_rate, 2),
            "data": msg_dict,
        }
    
    def _msg_to_dict(self, msg) -> dict:
        """Convert ROS2 message to nested dictionary."""
        import inspect
        
        result = {}
        
        # Get all slots (fields) from the message
        if hasattr(msg, '__slots__'):
            for field in msg.__slots__:
                value = getattr(msg, field, None)
                
                # Recursively handle nested messages
                if hasattr(value, '__slots__'):
                    result[field] = self._msg_to_dict(value)
                # Handle arrays
                elif isinstance(value, (list, tuple)):
                    if len(value) > 0 and hasattr(value[0], '__slots__'):
                        result[field] = [self._msg_to_dict(item) for item in value]
                    else:
                        result[field] = list(value)
                # Handle primitive types
                else:
                    result[field] = value
        
        return result
    
    def _build_topics_snapshot(self) -> dict:
        """Build TopicsSnapshot for /telemetry/topics endpoint."""
        import time
        return {
            "timestamp": time.time(),
            "topics": list(self._topic_updates.values()),
        }
    
    def _publish_telemetry(self):
        """Aggregate data and POST to backend."""
        snapshot = self._build_snapshot()
        topics_snapshot = self._build_topics_snapshot()
        
        try:
            # Post main telemetry
            requests.post(
                f"{self._backend_url}/telemetry/record",
                json=snapshot,
                timeout=1.0,
            )
            
            # Post raw topics (separate endpoint)
            requests.post(
                f"{self._backend_url}/telemetry/topics/update",
                json=topics_snapshot,
                timeout=1.0,
            )
        except requests.exceptions.RequestException as exc:
            self.get_logger().error(f"Failed to post telemetry: {exc}")
```

```typescript
function TopicInspector({ topics }: TopicInspectorProps) {
  const [expandedTopics, setExpandedTopics] = useState<Set<string>>(new Set())
  const [searchFilter, setSearchFilter] = useState('')
  
  if (!topics || topics.topics.length === 0) {
    return (
      <div className="topic-inspector">
        <div className="inspector-header">
          <h3>Topic Inspector</h3>
          <span className="status-badge offline">No topics</span>
        </div>
        <p className="inspector-empty">Waiting for ROS2 topics...</p>
      </div>
    )
  }
  
  const toggleTopic = (topicName: string) => {
    const newExpanded = new Set(expandedTopics)
    if (newExpanded.has(topicName)) {
      newExpanded.delete(topicName)
    } else {
      newExpanded.add(topicName)
    }
    setExpandedTopics(newExpanded)
  }
  
  const filteredTopics = topics.topics.filter(topic =>
    topic.topicName.toLowerCase().includes(searchFilter.toLowerCase())
  )
  
  return (
    <div className="topic-inspector">
      <div className="inspector-header">
        <h3>Topic Inspector</h3>
        <span className="status-badge online">
          {topics.topics.length} topics
        </span>
      </div>
      
      <input
        type="text"
        className="topic-search"
        placeholder="Filter topics..."
        value={searchFilter}
        onChange={(e) => setSearchFilter(e.target.value)}
      />
      
      <div className="topic-list">
        {filteredTopics.map((topic) => {
          const isExpanded = expandedTopics.has(topic.topicName)
          const age = Date.now() / 1000 - topic.timestamp
          const isStale = age > 2.0
          
          return (
            <div key={topic.topicName} className="topic-item">
              <div
                className="topic-header"
                onClick={() => toggleTopic(topic.topicName)}
              >
                <span className="topic-toggle">{isExpanded ? '▼' : '▶'}</span>
                <div className="topic-info">
                  <strong>{topic.topicName}</strong>
                  <span className="topic-type">{topic.messageType}</span>
                </div>
                <div className="topic-meta">
                  <span className={`topic-rate ${isStale ? 'stale' : ''}`}>
                    {topic.updateRateHz.toFixed(1)} Hz
                  </span>
                  {isStale && <span className="stale-badge">STALE</span>}
                </div>
              </div>
              
              {isExpanded && (
                <div className="topic-data">
                  <JsonView data={topic.data} />
                </div>
              )}
            </div>
          )
        })}
      </div>
    </div>

// JSON tree viewer component
function JsonView({ data, level = 0 }: { data: any; level?: number }) {
  if (data === null || data === undefined) {
    return <span className="json-null">null</span>
  }
  
  if (typeof data === 'number') {
    return <span className="json-number">{data.toFixed(4)}</span>
  }
  
  if (typeof data === 'string') {
    return <span className="json-string">"{data}"</span>
  }
  
  if (typeof data === 'boolean') {
    return <span className="json-boolean">{data.toString()}</span>
  }
  
  if (Array.isArray(data)) {
    // Show array length for large arrays
    if (data.length > 10) {
      return (
        <span className="json-array">
          [Array({data.length})] {data.slice(0, 3).map(String).join(', ')}...
        </span>
      )
    }
    return (
      <span className="json-array">
        [{data.map((item, i) => (
          <span key={i}>
            <JsonView data={item} level={level + 1} />
            {i < data.length - 1 && ', '}
          </span>
        ))}]
      </span>
    )
  }
  
  if (typeof data === 'object') {
    const entries = Object.entries(data)
    return (
      <div className="json-object" style={{ marginLeft: `${level * 16}px` }}>
        {entries.map(([key, value]) => (
          <div key={key} className="json-field">
            <span className="json-key">{key}:</span>{' '}
            <JsonView data={value} level={level + 1} />
          </div>
        ))}
      </div>
    )
  }
  
  return <span>{String(data)}</span>
}
```

### 11.4 Speed Configuration Answer

**The robot's max speed is configurable at multiple levels:**

1. **Navigator level**: `max_linear_speed` in `navigator_params.json` (default 0.50 m/s)
2. **Motor level**: `MOTOR_MAX_SPEED` environment variable (default 50/100)
3. **Dynamic**: Speed is calculated based on obstacles and steering angle

**Recommended tuning**:
- Start at `max_linear_speed: 0.30` for initial testing
- Monitor actual speeds in telemetry UI
- Increase gradually based on performance
