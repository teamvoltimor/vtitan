# Welcome to the Documentation

Welcome to the official documentation portal for this project. This site is designed to provide clear, organized, and easily navigable documentation for users and developers alike.

---

## 📚 Structure

- **Sidebar Navigation:**  
  Use the sidebar on the left to browse all available documentation pages. The navigation reflects the folder and file structure of the documentation, making it easy to find what you need.

- **Versioned Documentation:**  
  Documentation is organized by version. You can find different versions (e.g., `v1`, `v2`) under the sidebar. This allows you to reference documentation relevant to the version you are using.

- **Landing Page:**  
  This page serves as the starting point, introducing the documentation structure and how to navigate the site.

---

## 🔍 Features

- **Dark, Minimalist Design:**  
  The site uses a dark theme for readability and focus, with a clean and minimalist layout.

- **Search Functionality:**  
  Use the search bar at the top to quickly find topics, keywords, or specific documentation pages.

- **Code Highlighting:**  
  Code snippets are presented with syntax highlighting for better readability.

- **Custom Shortcodes:**  
  Look out for special callouts like notes, warnings, and tips, which are highlighted using custom shortcodes.

---

## 🚀 Getting Started

1. **Browse the Sidebar:**  
   Explore the documentation by selecting topics from the sidebar.

2. **Switch Versions:**  
   If you need documentation for a different version, select the appropriate version folder in the sidebar.

3. **Use Search:**  
   Enter keywords in the search bar to quickly locate information.
